    Lightweight IP discovery
    with quarantine logic

    Stop guessing which IPs are free. ns-lite scans your network, tracks availability over time, and won't release an IP just because a firewall dropped a ping.

    Get Started Quick Start GitHub

    3 Commands

    0 Downtime

    Why ns-lite?

    Safe quarantine logic

    No false frees. An IP must miss multiple scans and survive a quarantine period before it's marked available. Firewall flaps won't cost you.

    :material雷达屏幕:

    Multi-probe detection

    ARP, ICMP echo, ICMP timestamp, TCP SYN — uses whatever your privilege level allows. Records which probe actually worked.

    Group-based organization

    Separate your infra, database, and app IPs. Each group has its own quarantine thresholds and settings.

    LDAP authentication

    Token-based API auth backed by LDAP. CLI stores tokens automatically. Dev mode skips LDAP entirely — no server needed for local work.

    CSV/XLSX import

    Drop your IPs in a spreadsheet, import them. Hostname and group columns are optional — ns-lite handles the rest.

    CLI + REST API

    Use it from the terminal or wire it into Terraform. JSON output for automation, REST API for integration.

    Zero bloat

    No dashboard, no scheduler, no database server. SQLite, nmap, and a CLI. That's it.

    See it in action

    Terminal

    # Import your IPs
ns-lite import --file datacenter-ips.csv

# Scan them
ns-lite scan --group infra

# Get available IPs for provisioning
ns-lite available --group infra --count 3

# API auth (optional, for API access)
ns-lite auth --username jsmith

    How quarantine works

    1

    IP responds to scan

    ACTIVE_DETECTED

    →

    2

    IP stops responding

    UNCERTAIN_FIREWALLED

    →

    3

    Misses keep coming

    consecutive_misses++

    →

    4

    Threshold + time met

    AVAILABLE_CANDIDATE

    This two-factor approach (miss count and elapsed time) prevents premature reclaiming of IPs that are temporarily unreachable due to firewalls, maintenance, or network issues.

    Built for infrastructure teams

    Terraform integration

    Query available IPs directly from your Terraform workflows.

    data "http" "available_ips" {
  url = "http://ns-lite:8000/api/available?group=infra&count=3"
}

    Per-group quarantine

    Different thresholds for different workloads. Database servers get stricter quarantine than app servers.

    Multi-privilege scanning

    Works with or without root. Adapts probe types based on what's available — ARP when privileged, TCP connect when not.
