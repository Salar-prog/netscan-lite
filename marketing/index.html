The problem

You don't know what's on your network until something breaks.

Most IP management is manual, fragile, and reactive. You scan once, write down what you find, and hope nothing changes. ns-lite changes that — it scans continuously, tracks state over time, and tells you when a device has been gone long enough to release its IP.

🔇 Silent failures

A server goes down on Friday. Nobody notices until Monday's deploy fails because the IP it needed was reused.

📋 Spreadsheet archaeology

Your "IP inventory" is a spreadsheet from 2023 that nobody updates. Half the entries are wrong. The other half are guesses.

⏱️ Manual quarantine

You ping an IP once, decide it's dead, and reassign it. Then the original device comes back and you have an IP conflict.

What it does

Built for the IPs you actually manage.

Not a full network scanner. Not an IPAM tool. A focused utility that scans specific IPs, tracks their status, and lets you provision from the ones that are available.

🔬

Multi-probe detection

Tries ARP, ICMP, and TCP SYN probes depending on privilege level. Records which method actually found the device — not just whether it responded.

🛡️

Quarantine logic

An unresponsive host doesn't become "available" immediately. It enters quarantine and must miss multiple consecutive scans over a configurable duration before its IP is released.

📊

Per-group settings

Different networks, different rules. Set custom miss thresholds and quarantine durations for each group of IPs.

🔌

REST API + Dashboard

Full API for integration with provisioning tools. React dashboard for visual overview. WebSocket updates for real-time scan progress.

🔐

LDAP authentication

Enterprise-grade auth with group-based access control. Admin operations restricted to configured LDAP groups. JWT tokens for API access.

📦

Import from CSV/XLSX

Drop in a spreadsheet with IP addresses, hostnames, and groups. No schema migration, no API calls — just import and scan.

How it works

Three commands. One clear picture.

Import your IPs, scan them, and get back the ones that are ready. ns-lite handles the quarantine logic in between.

01

Import

Load your IP ranges from a CSV or XLSX file. Group them by network, environment, or whatever makes sense.

ns-lite import-cmd ips.csv
02

Scan

ns-lite probes each IP with multiple methods and records the result. Hostnames are resolved via reverse DNS.

ns-lite scan --group infra
03

Provision

Get the IPs that are confirmed available. ns-lite only returns hosts that have passed the quarantine period.

ns-lite available --count 3
Quick start

Up and running in 30 seconds.

Install, import, scan. No config needed for local use.

# install
pip install "netscan-lite[xlsx]"

# import your IPs
ns-lite import-cmd your-ips.csv

# scan and get available IPs
ns-lite scan
ns-lite available --count 5
